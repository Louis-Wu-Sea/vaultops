# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-03-24

### Added
- Open-source release under MIT license
- 43 MCP tools for task management, sprint planning, role enrichment, meetings, and cross-project intelligence
- 27 Claude Code slash commands (`/vault:*`)
- TUI dashboard with multi-project aggregate view
- CLI (`vaultops`) for project onboarding and management
- One-command installer with auto-dependency setup
- Obsidian vault integration with YAML frontmatter and wiki-links
- Task-as-Code verify contracts
- Predictive Brain for cycle time and risk forecasting
- Sprint management with burndown charts (Mermaid)
- Meeting notes with action item dispatch to project task boards
- Cross-project task linking and dependency graphs
- Architecture radar for coupling detection
- Standalone HTML stakeholder reports
- Obsidian canvas generation (kanban, sprint, dependency boards)

### Removed
- Paid subscription system (Stripe, crypto payments)
- License key validation and activation
- User portal (sign-in, dashboard, upgrade)
- Code obfuscation
